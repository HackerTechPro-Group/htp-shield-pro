# HTP Shield Pro

**A free browser extension by HackerTechPro Group**

HTP Shield Pro is a browser extension designed to help block unwanted ads, trackers, and pop-ups. It provides customizable filtering options, website whitelist controls, and domain activity statistics.

## Features

- Ad and tracker blocking
- Pop-up and suspicious redirect protection
- Domain activity statistics
- Custom filter support
- Website whitelist controls
- Enable and pause protection options

## Installation

### Step 1: Download

Download the latest ZIP package from the [Releases page](https://github.com/HackerTechPro-Group/htp-shield-pro/releases).

### Step 2: Extract the ZIP

Extract the downloaded ZIP file to a folder on your computer.

The project folder should contain `manifest.json` directly, along with the JavaScript files and the `icons` folder. Do not select a parent folder containing another nested project folder.

### Step 3: Open Chrome Extensions

Open Google Chrome and enter this address in the address bar:

`chrome://extensions`

### Step 4: Enable Developer mode

Turn on **Developer mode** on the Extensions page.

### Step 5: Load the extension

Click **Load unpacked** and select the project folder containing `manifest.json`.

### Step 6: Verify installation

Confirm that HTP Shield Pro appears on the Extensions page. You can then open the extension from Chrome's Extensions menu.
